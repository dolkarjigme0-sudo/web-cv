# Jigme Choeying Dolkar — Web CV

A responsive, static portfolio site built with plain HTML, CSS and JavaScript. Open `index.html` directly in a browser or deploy this folder to a static web host.

## Files

- `index.html` — page content and section structure
- `styles.css` — visual system and responsive layouts
- `script.js` — mobile navigation, project filters, draggable project carousel and scroll reveals
- `assets/logos/jcd_logo.png` — JCD mark supplied with the brand assets

The page uses the brand palette from the supplied guide: black `#000000`, muted gold `#C8A96B`, warm cream `#F7F5EF` and white `#FFFFFF`, with a deep forest green shell. DM Sans is the primary typeface, with a system sans-serif fallback if Google Fonts is unavailable. Motion respects the visitor’s reduced-motion preference. Certificate PDFs are shown in an inline, horizontally scrollable gallery.
